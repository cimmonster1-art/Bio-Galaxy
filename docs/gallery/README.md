# Bio Galaxy — Frame Gallery

A curated set of frames captured from the live Bio Galaxy atlas (real-time
Three.js / WebGL), assembled into a browsable gallery. Open
[`index.html`](./index.html) in a browser for the full animated gallery with
lightbox, or upload the frames in [`frames/`](./frames) directly to the
project's image gallery.

The set is ordered as one continuous dive down the zoom axis — the observable
cosmos to a single atom — so no two frames look alike.

## Recommended upload order & captions

Devpost shows the first image as the cover and allows up to 15 images at
5 MB each; every frame below is a 3024×2016 PNG well under that limit.

| # | File | Caption to paste |
|---|------|------------------|
| 1 | `frames/00-search-anything.png` | Search anything physical — type a galaxy, organism, protein, molecule, or atom and watch it render live in 3D. |
| 2 | `frames/01-cosmos.png` | Cosmos — the observable universe as a cosmic web of named stars and galaxies, from real star catalogs. |
| 3 | `frames/02-galaxy.png` | Galaxy — hundreds of billions of stars resolved into a luminous spiral disk. |
| 4 | `frames/03-solar-system.png` | Planetary system — worlds on eased orbits around their star, with source-cited bodies. |
| 5 | `frames/04-biome.png` | Biome — a living region with its own climate, vegetation, and animal life. |
| 6 | `frames/05-cell.png` | Cell — the interior of a single living cell, the smallest unit of life. |
| 7 | `frames/06-organelle.png` | Organelle — a specialized compartment that partitions the chemistry of the cell. |
| 8 | `frames/07-atom.png` | Atom — the bottom of the dive: a nucleus wrapped in shells of bonding electrons. |
| 9 | `frames/08-mitochondrion.png` | Mitochondrion — the folded double-membrane powerhouse that produces ATP. |
| 10 | `frames/09-red-blood-cell.png` | Red blood cell — a biconcave cell packed with hemoglobin, ferrying oxygen. |
| 11 | `frames/10-atp-synthase.png` | ATP synthase — the rotary molecular machine of the inner mitochondrial membrane. |
| 12 | `frames/11-hemoglobin.png` | Hemoglobin — the four-subunit oxygen-carrying protein, structure from RCSB PDB. |

Frames are educational visualizations; visual scale is compressed for
legibility rather than drawn true-to-scale.
