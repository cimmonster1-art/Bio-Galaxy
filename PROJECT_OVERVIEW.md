# Bio Galaxy - project overview

Interactive biological atlas with a physical-scale navigation system and a separate taxonomy lane.

**Stack:** React, TypeScript, Vite, Three.js, Express.

**Status:** Public source; submitted to the 3D Websites Hackathon on Devpost.

## Review this project

1. Read the root README for architecture and setup.
2. Inspect the implementation and tests, including external-service boundaries.
3. Run the repository's checks in a configured development environment:

```bash
npm run lint
npm test
npm run build
```

These are verification commands, not a claim that every check has passed on the current commit.

## Boundaries

Educational visualization; compressed visual scales and external scientific data. No clinical or diagnostic validation claimed.

This is personal project work developed with AI assistance. No paid-client history, commercial adoption or award is implied.
